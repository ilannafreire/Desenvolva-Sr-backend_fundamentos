## Sobre o programa

O **Desenvolva+ 2026** é um programa gratuito de formação em tecnologia realizado pelo **Mercado Livre (MELI)** em parceria com a [**Ada Tech**](https://ada.tech/).

É um programa de aceleração de alta performance voltado a talentos com deficiência que desejam atuar como **desenvolvedores Back-End Plenos ou Seniores** em um dos maiores ecossistemas de tecnologia da América Latina. As trilhas abrangem Python, Go e Java.

| Formato       | Carga horária    | Duração | Trilhas Back-End | Participantes |
| ------------- | ---------------- | ------- | ---------------- | ------------- |
| Aulas remotas | Mais de 300 horas | 5 meses | Python, Go e Java | 50 pessoas |

Além da formação técnica, o programa prepara os participantes para o processo seletivo do Mercado Livre, com aprofundamento técnico, simulações práticas e foco em performance.

### Pilares da formação

- Linguagens e stacks como Python, Java e Go
- Criação de APIs REST
- Programação Orientada a Objetos (POO)
- Testes automatizados
- Arquitetura de microsserviços

---

## Estrutura do programa

O programa é dividido em três módulos:

### Módulo 1 — Introdução à Arquitetura de Software

- Princípios SOLID
- Clean Architecture
- Padrões de projeto GoF
- Monolitos vs. microsserviços
- API Gateway
- Padrão SAGA
- Domain-Driven Design (DDD)
- OWASP

### Módulo 2 — Tópicos de Fundamentos em Engenharia Backend

Este módulo aborda fundamentos importantes para o desenvolvimento de sistemas Back-End.

- Programação paralela e assíncrona
- Frameworks para desenvolvimento de APIs REST
- Testes de carga com **k6**
- Observabilidade com **OpenTelemetry**
- Inteligência artificial aplicada

### Módulo 3 — Arquitetura de Software e Ágil 2

- Microsserviços avançados
- Cache com **Redis**
- Mensageria com **RabbitMQ** e **Kafka**
- Padrão SAGA: orquestração e coreografia
- Testes de contrato

---

## Tópicos de Engenharia Back-End

| Tema                                 | Descrição                                                                                                |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Programação paralela e assíncrona | Threads, concorrência,`ExecutorService`, `CompletableFuture` e processamento não bloqueante em Java. |
| APIs REST                            | Construção de APIs REST com frameworks do ecossistema Java.                                              |
| Testes de carga                      | Simulação de tráfego e análise de desempenho com k6.                                                   |
| Observabilidade                      | Coleta de traces, métricas e logs com OpenTelemetry.                                                      |
| IA aplicada                          | Uso de inteligência artificial no desenvolvimento e em soluções backend.                                |

## Como executar

- [Maven](https://maven.apache.org/) ou [Gradle](https://gradle.org/)
- [k6](https://k6.io/) para executar os testes de carga
- [Git](https://git-scm.com/)
